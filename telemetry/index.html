Where it fits

One correlation layer across the trust chain

AgentTrust Telemetry sits across the four AgenTrust standards. It records runtime facts in a backend-neutral contract, correlates them with the application's existing OpenTelemetry context, and can finalize a complete durable evidence set into a TRACE record.

Contract

The events an enterprise integration needs

Policy and approval

Allow, deny, challenge, error, enforcement mode, policy identity, human approval requests, resolutions, and execution outcome.

Actions and data flow

Resolved tool, MCP, A2A, file, HTTP, and database attempts plus metadata-only source-to-destination classification.

Usage and cost

Per-call facts and conservative per-agent or per-workflow rollups, with explicit cost provenance and no invented prices.

Evidence lifecycle

Run checkpoints and completeness state kept separate from lossy operational telemetry, with optional TRACE finalization.

Adopt it

Keep the stack you already operate

The reference SDK uses the caller's current OpenTelemetry span. It does not install a provider, processor, exporter, collector, or global propagator. W3C trace context and durable run, workflow, and agent identifiers preserve relationships across process boundaries.

Privacy boundary: the metadata-only profile prohibits raw prompts, outputs, source code, tool arguments or results, credentials, and authorization tokens. Propagated identifiers are correlation data, not proof of identity or authorization.

Until the first registry release, install the Python SDK from a checkout:

git clone https://github.com/agentrust-io/agentrust-telemetry
cd agentrust-telemetry
python -m pip install -e ".[otel]"

The TypeScript reference SDK is in packages/typescript. PyPI and npm package publication is being prepared; this page will switch to registry install commands after the first release.

Boundaries

What it deliberately does not become

It is not a tracing backend, dashboard, policy engine, approval workflow, agent framework, model-price catalog, or duplicate implementation of OpenTelemetry GenAI instrumentation. Operational spans may be sampled or dropped; complete audit evidence must be accumulated durably before any TRACE claim is made.
